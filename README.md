# BIBLIOTHEQUE

Application web de gestion d'une bibliothèque personnelle.

## Objectif

Le projet est une refonte complète d'une première version développée
en PHP et MySQL.

La nouvelle architecture séparera le frontend et le backend.

## Stack cible

### Backend
- Java
- Spring Boot
- Spring MVC
- Spring Security
- Spring Data JPA
- Hibernate
- JWT

### Frontend
- HTML
- CSS
- JavaScript

### Données
- PostgreSQL
- Supabase

### Déploiement
- Vercel pour le frontend
- Render pour le backend
- Supabase pour PostgreSQL et le stockage des images

## Structure

- `backend/` : API Spring Boot
- `frontend/` : interface utilisateur
- `docs/` : documentation
- `legacy/php/` : première version PHP/MySQL
